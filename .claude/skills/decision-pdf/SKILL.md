# PDF доклад за решение

Структура:
1. Корица: заглавие, въпросът, дата.
2. „Отговорът“: присъдата в едно изречение, 3–5 ключови числа в големи карти, препоръка и първа стъпка.
3. По една страница на тема: заглавие-извод, графика или таблица, до 5 изречения, източници под линия.
4. Сценарии и рискове.
5. Приложение: източници с линкове и дата; методология; кое е [ОЦЕНКА].

Дизайн: A4, чист шрифт, най-много 2 акцентни цвята, едно послание на страница.

Как:
1. Графиките като PNG с matplotlib в reports/figures/ (заглавие-извод на всяка).
2. reports/<име>.html с CSS за печат: `@page { size: A4; margin: 15mm; }`, `break-inside: avoid` за карти и таблици.
3. PDF с Chrome (пълни пътища):
   - Mac: `"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless --no-pdf-header-footer --print-to-pdf="<пълен път>/reports/<име>.pdf" "<пълен път>/reports/<име>.html"`
   - Windows: `"C:\Program Files\Google\Chrome\Application\chrome.exe" --headless --no-pdf-header-footer --print-to-pdf="<пълен път>\reports\<име>.pdf" "<пълен път>\reports\<име>.html"`
4. Прочети PDF-а страница по страница: нищо извън полето, няма празни страници, всяка страница има извод. Кажи броя страници.
