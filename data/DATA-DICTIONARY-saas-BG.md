# Речник на данните · AI SaaS за онлайн магазини (синтетични данни)

Файлове: `saas_subscriptions_2025_2026.csv` (един ред = един абонамент) и `saas_marketing_spend.csv` (разходи по канал и месец).
Данните са **синтетични**, създадени за курса. Към дата 30.09.2026.

## saas_subscriptions_2025_2026.csv
| Колона | Значение |
|---|---|
| customer_id | номер на абонамента |
| email_hash | анонимизиран имейл (един човек = един хеш) |
| signup_date | дата на регистрация |
| plan | план: Starter (19 €), Pro (49 €), Business (149 € + 25 € за всяко място над 3) |
| seats | брой места (потребители) |
| discount_pct | отстъпка в % |
| monthly_price_eur | месечна цена след отстъпката |
| currency | валута, в която е записана цената |
| country | държава |
| channel | откъде е дошъл клиентът |
| cancel_date | дата на отказ (празно = активен) |
| cancel_reason | причина за отказ |

## saas_marketing_spend.csv
| Колона | Значение |
|---|---|
| month | месец (ГГГГ-ММ) |
| channel | канал |
| spend_eur | разход в евро (реклами, комисиони, награди за препоръка) |

Бележка: България мина към еврото на 1.1.2026.

## saas_clean.csv (Ден 2, Лаб 4)
Почистената таблица на абонаментите: 2 694 реда, един ред = един реален клиент. Същите колони като `saas_subscriptions_2025_2026.csv`.
Ако вашата почистена таблица от Лаб 2 е готова, работете с нея. Ако не е, ползвайте този файл.

Какво е почистено спрямо суровия файл:
- махнати са дубликатите и тестовите акаунти;
- всички цени са в евро (`currency` е навсякъде EUR);
- имената на плановете са уеднаквени: Starter, Pro, Business;
- датите са във формат ГГГГ-ММ-ДД;
- няма отказ преди регистрация и няма отрицателни цени;
- каналът е попълнен при всички клиенти.

Данните са към 30.09.2026.
